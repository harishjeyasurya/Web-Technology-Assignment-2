# Student Admission Portal — PDF Code Extraction

This ZIP was prepared from `WT_Assignment2_StudentAdmissionPortal.pdf`. The code listings are extracted from the PDF text and arranged by question for easier GitHub upload.

## Folders
- `Question1_Frontend/`: the PDF's HTML, CSS and JavaScript listings.
- `Question2_PHP_MySQL/PDF_Snippets/`: PHP code excerpts shown in the PDF.
- `Question3_Java_Servlet/PDF_Snippets/`: Java, JSP and XML excerpts shown in the PDF.
- `Database/student_portal.sql`: SQL script shown in the PDF.

## Important source limitation
The PDF does **not** provide complete source files for every PHP and Java/JSP file. In Questions 2 and 3, several entries are explicitly presented as “Code snippet” or show only selected portions of a file. Those are saved with `.snippet` in the filename so they are not mistaken for complete, runnable applications. I have not silently invented the missing code or represented it as text from the PDF.

The HTML form intentionally retains the PDF's original action path: `../PHP/insert_student.php`. The PDF's folder layout is `Frontend/`, `PHP/`, `Servlet/`, and `Database/`.

## GitHub
Unzip the archive, inspect the files, and upload the folder contents to your repository. The Q1 front-end files and SQL listing are complete as represented in the PDF; the Q2/Q3 excerpts need the remaining source code before those applications can be run end-to-end.
